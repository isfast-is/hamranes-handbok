# Hamranes — handbók hússins og eiganda

Aðgangsvarin vefútgáfa handbókar hússins og handbókar eiganda fyrir
Hjúkrunarheimilið Hringhamri 43, Hafnarfirði.

- `index.html` — aðgangssíða (PBKDF2 + AES-256-GCM í vafra)
- `content.enc` — dulkóðuð handbókarsíða, unnin úr isfast-qc gagnagrunninum
- `handbok.pdf.enc` — dulkóðuð prentútgáfa (sótt með „Sækja PDF" hnappnum)

Byggingarforrit (build.py, app_template.html, print_render.py) eru ekki í
þessu opinbera safni; þau eru keyrð á vinnuvél Ísfast og afrit geymd í
verkefnismöppu. Aðeins dulkóðað efni er birt hér.
